# Contributing

Ideas, fixes, and examples from other regions are welcome. Include a small
synthetic reproduction for geometry or altitude issues, and explain the actual
coordinate and vertical reference of any terrain input. Do not upload private
flight exports, credentials, map caches, or third-party datasets without rights
to redistribute them. Prefer synthetic fixtures in tests.

Install with `python -m pip install .` and run
`python -m unittest discover -s tests -v`. Keep display smoothing separate from
distance calculations, and preserve provenance for data exclusions.

For comments on the original photography map, feel free to join the discussion:
https://www.reddit.com/r/sanfrancisco/comments/1x3fn8m/if_you_want_to_get_close_to_the_blue_angels_today/
